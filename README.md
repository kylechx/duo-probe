# duo-probe

Throwaway test pages. Do Home Screen web apps on the iPhone Duo get the right-hand status column back
on iOS 27.2 when they use `apple-mobile-web-app-status-bar-style: black-translucent`?

- `control/`: default status bar.
- `translucent/`: `black-translucent`.

Both pages print the window size and safe-area insets. Nothing else is here, and the repository will be deleted after the test.
