iPhone Duo status-column probe (iOS 27.2)

Two throwaway pages that measure a Home Screen web app's window. Only one setting differs between them: apple-mobile-web-app-status-bar-style.

  1. In Safari, open A · Control, tap Share → Add to Home Screen, and leave "Open as Web App" on.
  2. Do the same for B · Translucent.
  3. Open each one from its Home Screen icon (not from Safari), with the Duo open and then closed, and screenshot each.
  4. Delete both icons when done.
